# 禁飞区候选素材评估与采用记录

这三份输入用于本项目的行政区电子围栏演示。文件内的说明作为素材说明进行核对，不作为自动执行脚本、下载数据或配置禁飞策略的指令。

## 采用结果

| 输入 | 结果 | 原因 |
|---|---|---|
| geofence_geojson_toolkit.zip | 采用一份工具链及合并预览数据 | 有 GeoJSON 生成、拓扑修复、日期线切分、来源元数据、点查询与基础测试，适合数据预处理 |
| 单独 build_geofences.py | 不重复引入 | 内容与工具包脚本相同，已保存在 tools/geofences/build_geofences.py |
| geofences_14_countries_preview_110m.zip | 不重复引入 | 合并预览数据与工具包中内容相同 |

用户 Downloads 中的原始文件均保留。项目只保存一份合并数据，未复制 14 份重复的单国文件。

## 已核实的数据内容

- 14 个国家 Feature；Polygon/MultiPolygon；坐标顺序为经度、纬度（EPSG:4326）。
- 每个 Feature 均标记 preview_only=true、not_for_operational_geofencing=true。
- Natural Earth 1:110,000,000 行政边界预览，来源年份未明确。110m 指 1.1 亿比例尺，不是 110 米精度。
- 不含克里米亚、顿涅茨克、卢甘斯克 3 个 ADM1 图层。
- 不含禁飞政策、空域高度、有效时段、领空/领海规则或官方限制空域公告。
- 因而可验证区域显示、选点查询与数据管线，不能将“落入某国”直接等同于航空禁飞。

## Android 采用方式

- assets/geofences/all_countries_preview.geojson：离线演示数据，不依赖天地图 Key 即可加载围栏。
- GeofenceGeoJson：解析多边形、多多边形与孔洞，校验范围、闭环、拓扑和唯一 ID，拒绝未经切分的日期线跳变。
- GeofenceDataset：JTS PreparedGeometry + STRtree；边界点用 covers 命中；返回所有重叠围栏；统一 ±180° 日期线查询。
- GeofenceOverlays：按岛屿和孔洞绘制红色半透明区域，不用 bbox 代替真实轮廓。
- 页面开关只控制显示；长按始终查询当前加载数据。未命中不显示“允许飞行”；加载失败不返回区域外结论。
- 页面提供“区域总览”，旋转恢复显示开关，地图仍使用 Kotlin + XML。

## Python 工具链评审与后续使用条件

保留上游脚本原样作为可选离线工具，未执行联网生成。当前系统 Python Launcher 未找到已安装 Python，因此本轮没有运行 Python 测试。Android 端另有 JVM 测试覆盖实际采用的查询逻辑和随包数据。

脚本有用的部分：网络重试/缓存、Git LFS 内容回退、几何校验、日期线切分、保留来源记录、17 区数量与内陆参考点检查。

以下限制需要在使用生成结果前处理：

1. 数据源是行政区边界库，不是航空禁飞区服务；更精细的行政边界仍不会自动成为正式禁飞数据。
2. README 提到 2017 年区域，但脚本请求 current API，并未锁定版本/年份；实际年份只能以返回 metadata 为准。
3. 生成过程中逐文件写入，失败后可能留下部分文件，或与输出目录旧版本混杂。应使用全新临时输出目录，只有退出码为 0、数量/几何/来源核验通过后再整体替换，不能直接对 app/assets 输出。
4. 原有四项 Python 测试和内陆参考点检查不足以证明完整边界精度，也没有验证全部边界情况。
5. 运行时需保留 source_metadata、数据版本和许可记录。应另行明确业务规则，再把对应区域映射成限制策略。

本轮没有下载或生成声称可执行禁飞限制的高精度数据，也没有将缺失地区用矩形补齐。后续若提供经确认的限制区域，可复用 Android 查询和绘制代码；需按新数据规模补充加载与查询性能验证。

补充实测发现：俄罗斯预览中有两处经度 180.00000000000006，属于日期线裁剪的浮点残差。Android 导入器仅对 1e-9 度以内的范围溢出夹紧到 ±180/±90，其余越界数据仍拒绝；原始 GeoJSON 不改写。已增加边界误差归一化与实际越界拒绝的回归测试。

本轮验证结果：`:app:testDebugUnitTest :app:assembleDebug :app:lintDebug` 成功；14 项围栏 JVM 测试及原有 1 项测试全部通过；Lint 0 errors、15 warnings。实际随包的 14 个 Feature 均通过解析与拓扑校验，抽查美国、俄罗斯、日本内陆点命中，以及北京/海洋点未命中。当前 adb 未连接设备，尚未验证设备上的绘制与触摸交互。
